在设置中添加 MCP 后，可在此启停并查看工具列表。

为什么不用一条长滚动？

40 个技能把 MCP 顶出首屏；用户要记住「MCP 在最底下」。子标签把两套目录分开。

滚动条用在哪？

只用在列表区。搜索 / 筛选 / 子标签 / 详情条固定，滚列表时工具不丢。

详情怎么放？

钉在技能子页底部（约 160px），列表吃剩余高度。不做成左右分栏（侧栏太窄）。
